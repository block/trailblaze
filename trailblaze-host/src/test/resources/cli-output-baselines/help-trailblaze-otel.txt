Usage: trailblaze otel [-hV] [--post] [--endpoint=<url>]
                       [--service-name=<serviceName>] [<dir>]
Convert recorded spans to OpenTelemetry. Writes <session>/otel.json (OTLP/JSON)
for every session that recorded a trace, and with --post also sends them to an
OTLP endpoint. Defaults to the configured logs directory when <dir> is omitted.
      [<dir>]            A logs directory (holding per-session subdirectories)
                           or a single session directory. Defaults to the
                           configured logs directory.
      --endpoint=<url>   OTLP endpoint to send to. Implies --post. Port 4317 is
                           treated as gRPC, anything else as OTLP/HTTP.
  -h, --help             Show this help message and exit.
      --post             Also send the spans to an OTLP endpoint. Uses
                           --endpoint if given, otherwise
                           OTEL_EXPORTER_OTLP_TRACES_ENDPOINT /
                           OTEL_EXPORTER_OTLP_ENDPOINT, falling back to http:
                           //localhost:4318.
      --service-name=<serviceName>
                         Service name recorded in the exported resource.
                           Defaults to `trailblaze`.
  -V, --version          Print version information and exit.
