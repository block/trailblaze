Usage: trailblaze device install [-hV] [-d=<device>] APP
Install an app on a device, including one borrowed from another machine
      APP                 The .apk, .app or .zip to install
  -d, --device=<device>   Device to install on, as `trailblaze device list`
                            shows it. Defaults to `$TRAILBLAZE_DEVICE` if set,
                            otherwise this terminal's pin.
  -h, --help              Show this help message and exit.
  -V, --version           Print version information and exit.

Android takes an .apk; an iOS simulator takes an .app bundle or a .zip
holding one. A borrowed device's app is sent to the machine that lends it.

Example:
  trailblaze device install app-debug.apk --device android/emulator-5554
