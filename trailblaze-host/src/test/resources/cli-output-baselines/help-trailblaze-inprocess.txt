Usage: trailblaze inprocess [-hV] [COMMAND]
Check an app APK for in-process driver compatibility, and build a test APK that
drives it.
  -h, --help      Show this help message and exit.
  -V, --version   Print version information and exit.
Commands:
  probe-apk      Fingerprint an app APK and say whether the in-process driver
                   can attach to it.
  make-test-apk  Retarget a prebuilt in-process shell APK at one app and sign
                   it with that app's key. Stamps the instrumentation's target
                   package, injects trails / target config / scripted-tool
                   bundles, then signs. Writes a build record beside the output
                   APK.
