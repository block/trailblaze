Usage: trailblaze app [-hV] [--foreground] [--headless] [--status] [--stop]
                      [COMMAND]
Open Trailblaze App, starting the daemon if it is not running (use --headless
to start only the daemon).
`trailblaze app start` starts only the daemon, the same as `trailblaze app
--headless`.
      --foreground   Run the daemon in the foreground (blocks terminal). Use
                       for debugging with an attached IDE.
  -h, --help         Show this help message and exit.
      --headless     Start only the daemon, without opening Trailblaze App
      --status       Check if the daemon is running
      --stop         Stop the running daemon
  -V, --version      Print version information and exit.
