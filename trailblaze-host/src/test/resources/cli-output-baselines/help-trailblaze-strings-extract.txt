Usage: trailblaze strings extract [-hV] [--all] [--logs-dir=<path>]
                                  [<session-id>]
Write visible-strings.ndjson into each session's directory. One line per screen
capture, keyed by the screenshot filename so every string traces back to its
image.
      [<session-id>]      Session ID or unambiguous prefix. Defaults to every
                            session in the logs directory.
      --all               Keep the strings on every capture. By default a
                            capture that repeats the previous screen's text is
                            recorded as a repeat with its strings omitted.
  -h, --help              Show this help message and exit.
      --logs-dir=<path>   Directory to read sessions from. Defaults to the
                            configured logs directory.
  -V, --version           Print version information and exit.
