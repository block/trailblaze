Usage: trailblaze companion [-hV] [--agent-help] [COMMAND]
Attach a coding agent to Trail Runner while it authors a trail.
      --agent-help   Print the complete coding-agent workflow and wire contract.
  -h, --help         Show this help message and exit.
  -V, --version      Print version information and exit.
Commands:
  start       Start a companion authoring session.
  event       Append narration to a companion session.
  send        Send or retract Trail Runner UI guidance.
  listen      Stream human and lifecycle events as JSON Lines.
  disconnect  End a companion session.
  respond     Settle a request delegated by Trail Runner.
  agent-help  Print the complete coding-agent workflow and wire contract.
