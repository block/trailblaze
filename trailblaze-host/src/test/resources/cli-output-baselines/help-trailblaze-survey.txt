Usage: trailblaze survey [-hV] [--format=<format>] [--logs-dir=<path>]
                         [-o=<file>] [--survey=<name>]... [<session>...]
Run surveys over finished sessions, store their findings and labels in each
session, and print a report
Surveys load from the workspace you run this in. Each survey's find phase reads
every session, then label phases run over the batch. A survey that a selected
survey lists in `dependsOn` runs too, reusing a session's stored findings while
they are current.
      [<session>...]      Session id or unambiguous prefix, or a path: a
                            session directory, a directory of sessions, or a
                            session zip. Defaults to every session in the logs
                            directory.
      --format=<format>   What to print: markdown (default), summary, json, or
                            none.
  -h, --help              Show this help message and exit.
      --logs-dir=<path>   Directory session ids resolve in. Defaults to the
                            configured logs directory.
  -o, --out=<file>        Also write the JSON report to this file.
      --survey=<name>     Only run the survey exported under this name
                            (repeatable).
  -V, --version           Print version information and exit.
