Usage: trailblaze companion start [-hV] [--agent=<agent>] [--folder=<folder>]
                                  [--label=<label>] [--title=<title>]
                                  [--trails-dir=<trailsDir>]
Start a companion authoring session.
      --agent=<agent>     Agent type: claude or codex.
      --folder=<folder>   Trail folder relative to the workspace root.
  -h, --help              Show this help message and exit.
      --label=<label>     Agent label shown in Trail Runner.
      --title=<title>     Human-readable title shown in Trail Runner.
      --trails-dir=<trailsDir>
                          Workspace root (default: current directory).
  -V, --version           Print version information and exit.
